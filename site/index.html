🎼 juj 樂譜自動擷取工具（吉他譜／鋼琴譜）

上傳教學影片，自動擷取譜面、去除重複，預覽確認後緊密排版成 PDF。吉他譜、鋼琴譜都適用，使用時在網頁上選擇要擷取哪一種。

⚠️ 擷取出的樂譜建議只留作自己練習用，不要再轉傳，也不要販售；需要購買請與原曲譜製作者聯絡。

🎸🎹 樂譜自動擷取工具 本機連接埠 5001

上傳教學影片前，先在網頁上選擇「吉他譜」或「鋼琴譜」： 吉他譜會切成「和弦圖＋五線譜＋六線譜（含歌詞）」一行一行；鋼琴譜會切成「和弦名稱＋高音譜表＋低音譜表」一行一行。 程式會清掉播放提示框與游標、去除捲動造成的重複，預覽確認後再緊密排版成 PDF，省紙又好讀。 整頁都是譜的影片、譜只在畫面上方或下方的影片都能處理。 影片分析與 PDF 產生都在你自己的電腦上執行，影片內容完全不會離開你的裝置。

安裝與使用步驟

  1. 下載對應電腦（Windows / Mac）的 zip 檔，解壓縮到你想要的資料夾。
  2. 第一次使用前需要先安裝 Python 3.9 以上版本（一次性，之後不用再裝）： 到 python.org/downloads 下載安裝， Windows 使用者安裝時記得勾選「Add Python to PATH」。
  3. 啟動工具：Windows 雙擊資料夾裡的 start_windows.bat；Mac 雙擊 start_mac.command。 工具會自動用 Google Chrome 開啟（沒有安裝 Chrome 時改用預設瀏覽器）。
  4. 第一次開啟時出現安全警告是正常的（因為檔案是從網路下載的），處理方式：
    • Mac：出現「Apple 無法驗證…」時按「完成」（不要按「丟到垃圾桶」）， 接著打開「系統設定 → 隱私權與安全性」，往下捲到「安全性」，按「仍要打開」並輸入密碼，再雙擊一次即可。 （較舊的 macOS：在 Finder 對檔案按右鍵 →「打開」。）
    • Windows：出現藍色的「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」。
    只需要處理一次，之後雙擊就會直接啟動。
  5. 第一次啟動會自動安裝所需套件，需要等待幾分鐘；之後每次啟動只需幾秒鐘（http://127.0.0.1:5001）。使用時請不要關掉啟動後出現的黑色視窗。
  6. 先選「吉他譜」或「鋼琴譜」，上傳影片後會自動掃描擷取，在預覽區移除抓錯的行，選好紙張與譜的大小（可先預覽排版），再按「產生樂譜 PDF」下載。漏抓的地方可以用「手動補抓畫面」補上。
💡 這個下載版是完整的本機工具，包含「上傳影片」與「貼上影片網址下載」兩種模式；如果你想把它部署到自己有運算資源的伺服器上長期提供服務，解壓縮後的資料夾裡的 README.md 有完整的「部署到伺服器」說明。這個網頁本身只提供下載，不處理影片。
