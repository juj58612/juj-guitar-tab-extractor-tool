🎸 juj 吉他影片六線譜自動擷取工具

上傳吉他教學影片，自動去除重複畫面、擷取六線譜片段，依時間順序拼成完整樂譜 PDF。

下載到你自己的電腦上使用

這個網頁本身不處理影片——影片分析與 PDF 產生都是在你自己的電腦上執行， 影片內容完全不會離開你的裝置。下載並解壓縮後，依照你的作業系統點擊對應的啟動檔即可。

🪟 下載 Windows 版 guitar_tab_extractor_win.zip・約 15 MB 🍎 下載 Mac 版 guitar_tab_extractor_mac.zip・約 15 MB

安裝與使用步驟

  1. 下載對應版本的 zip 檔，解壓縮到你想要的資料夾。
  2. 第一次使用前需要先安裝 Python 3.9 以上版本（一次性，之後不用再裝）： 到 python.org/downloads 下載安裝， Windows 使用者安裝時記得勾選「Add Python to PATH」。
  3. 啟動工具：Windows 雙擊 start_windows.bat；Mac 雙擊 start_mac.command （Mac 如果顯示「無法開啟，因為來自不明開發者」，在 Finder 對檔案按右鍵 →「打開」即可，只需做一次）。
  4. 第一次啟動會自動安裝所需套件，需要等待幾分鐘；之後每次啟動只需幾秒鐘，會自動打開瀏覽器到 http://127.0.0.1:5001。
  5. 上傳影片、確認譜面框選區域、按下開始，等待處理完成後下載 PDF 即可。
💡 這個下載版是完整的本機工具，包含「上傳影片」與「貼上影片網址下載」兩種模式；如果你想把它部署到自己有運算資源的伺服器上長期提供服務，解壓縮後的資料夾裡的 README.md 有完整的「部署到伺服器」說明。
