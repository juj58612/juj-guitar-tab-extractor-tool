安裝與使用步驟（兩款工具通用）

  1. 下載對應版本、對應樂器的 zip 檔，解壓縮到你想要的資料夾（兩款工具可以各自解壓縮到不同資料夾，互不影響）。
  2. 第一次使用前需要先安裝 Python 3.9 以上版本（一次性，兩款工具共用，之後不用再裝）： 到 python.org/downloads 下載安裝， Windows 使用者安裝時記得勾選「Add Python to PATH」。
  3. 啟動工具：Windows 雙擊資料夾裡的 start_windows.bat；Mac 雙擊 start_mac.command （Mac 如果顯示「無法開啟，因為來自不明開發者」，在 Finder 對檔案按右鍵 →「打開」即可，只需做一次）。
  4. 第一次啟動會自動安裝所需套件，需要等待幾分鐘；之後每次啟動只需幾秒鐘，會自動打開瀏覽器（吉他版 http://127.0.0.1:5001，鋼琴版 http://127.0.0.1:5002）。
  5. 上傳影片、確認譜面框選區域、按下開始，等待處理完成後下載 PDF 即可。
💡 這兩個下載版都是完整的本機工具，包含「上傳影片」與「貼上影片網址下載」兩種模式；如果你想把它部署到自己有運算資源的伺服器上長期提供服務，解壓縮後的資料夾裡的 README.md 有完整的「部署到伺服器」說明。這個網頁本身只提供下載，不處理影片。
